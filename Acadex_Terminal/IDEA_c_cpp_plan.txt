Admin students aur subjects sambhalta hai.

2. C - KAUNSA DATA STRUCTURE KAHAN  (har ek ka ek asli kaam)
============================================================

 2.1 ARRAY  -> subjects ki list
 ------------------------------------------------------------
    char subjects[20][50];   int subjectCount;
    Admin  : Add subject (end mein daalo) , View subjects
    Student: upload karte waqt list dikhe -> number chuno (1. DBMS  2. DSA ...)
    Kyun   : subjects kam hain aur fixed max (20) -> array sahi hai
    Functions: addSubject , showSubjects , getSubject(index) , findSubject (linear search)

 2.2 SINGLY LINKED LIST  -> saare notes
 ------------------------------------------------------------
    struct Note { int id; char title[]; char subject[]; char uploader[];
                  Page* firstPage; Note* next; }
    Upload       -> insert at END (purana pehle , naya baad mein)
    View all     -> traverse , ek line mein:  #3  DBMS  Normalization  (by Rahul)
    Delete       -> id se dhoondho , list se nikaalo (delete at position)
    Kyun         : notes kitne honge pata nahi , beech se delete hota hai
    (tumhara LinkedList.c ka insert_end / delete_position yahin lagega)

 2.3 DOUBLY LINKED LIST  -> ek note ke pages
 ------------------------------------------------------------
    struct Page { int number; char text[1000]; Page* prev; Page* next; }
    Upload : student page by page text type kare -> har page insert at END
    Read   :  ---- Page 2 of 5 ----
              ...text...
              n = next   p = previous   q = back
    Kyun   : aage AUR peeche dono jaana hai -> prev + next pointer = doubly

 2.4 STACK  -> Undo last delete
 ------------------------------------------------------------
    Note delete kiya -> free() NAHI , stack pe PUSH
    "Undo last delete" -> POP -> note wapas notes list mein
    Do delete kiye -> undo pehle LAST wala wapas laata hai = LIFO
    Kyun   : recycle bin / Ctrl+Z jaisa - sabse naya delete pehle wapas
    Program band hone pe stack khaali (deleted notes tab jaake free)

 2.5 QUEUE  -> Read Later list
 ------------------------------------------------------------
    "Add note to Read Later" -> note id ENQUEUE (rear)
    "Read next from Read Later" -> FRONT wala note khule (pages wala reader) -> DEQUEUE
    Pehle add kiya , pehle padha = FIFO
    Kyun   : padhne ki line - jaise playlist / to-do

 C SUMMARY
    | DS                 | Feature            | Operations dikhte hain           |
    |--------------------|--------------------|----------------------------------|
    | Array              | subjects           | insert , traverse , linear search|
    | Singly linked list | notes              | insert end , traverse , delete   |
    | Doubly linked list | note ke pages      | insert end , next / prev         |
    | Stack              | undo delete        | push , pop , isEmpty             |
    | Queue              | read later         | enqueue , dequeue , front , isEmpty |


============================================================
3. C++ - OOP KAHAN
============================================================

 3.1 INHERITANCE  -> User se Student aur Admin
 ------------------------------------------------------------
                 User              (name , id , password)
                /    \
          Student    Admin
    Student ke paas rollNo , Admin ke paas email

 3.2 ABSTRACTION  -> abstract class + C ko chhupana
 ------------------------------------------------------------
    class User { virtual void showMenu() = 0; }   <- pure virtual = abstract class
    class NoteBook  -> andar C ke linked list / stack / queue functions bulata hai.
                       Menu bas  noteBook.upload()  bolta hai , usko pata hi nahi
                       andar linked list hai. = abstraction

 3.3 POLYMORPHISM  -> login ke baad ek hi line
 ------------------------------------------------------------
    User* user = login();      // Student ya Admin , jo bhi ho
    user->showMenu();          // Student ka menu ya Admin ka menu - khud decide
    [aur] function overloading: findUser(string rollNo) / findUser(int id)

 3.4 ENCAPSULATION  -> data private
 ------------------------------------------------------------
    class User { private: string password;
                 public:  bool checkPassword(string typed); }
    Password ka getter nahi -> bahar se padh hi nahi sakte.

 3.5 VECTOR  -> saare users
 ------------------------------------------------------------
    vector<User*> users;       // Admin + saare Students ek saath
    Login        -> vector mein dhoondho
    Add student  -> users.push_back(new Student(...))
    Remove       -> users.erase(...)
    Base pointer ka vector = polymorphism ke saath asli use

 3.6 FILE HANDLING (fstream)  -> data save / load
 ------------------------------------------------------------
    class FileManager {
        load() -> program khule:  data/users.txt , subjects.txt , notes.txt padho
        save() -> program band:   sab wapas likho
    }
    notes.txt mein har note ke pages bhi (page text ek line mein)
    Pehli baar files nahi -> ek default admin bana do

 C++ SUMMARY
    | Topic          | Kahan                                  |
    |----------------|----------------------------------------|
    | Encapsulation  | User ka private password               |
    | Abstraction    | abstract User , NoteBook class         |
    | Inheritance    | User -> Student , Admin                |
    | Polymorphism   | user->showMenu() , findUser overloading|
    | Vector         | vector<User*> users                    |
    | File handling  | FileManager load / save                |
