1. MAQSAD
------------------------------------------------------------
Student notes submit karta hai -> notes "pending" ho jaate hain
-> section ka CR approve / reject karta hai.

Rule: JO SABSE PEHLE BHEJA, USKA SABSE PEHLE REVIEW (First In First Out).

    Submit hue:  Rahul (10:00) -> Priya (10:05) -> Aman (10:20)

    FRONT -> [ Rahul ] [ Priya ] [ Aman ] <- REAR

    CR ko pehle Rahul ka note -> approve/reject -> DEQUEUE -> front pe Priya
    Naya submit (Neha, 10:30) -> ENQUEUE -> Aman ke PEECHE

Yeh "line" HUMARA C PROGRAM (queue) sambhalega, JavaScript nahi.

Abhi yeh kahan hota hai:
    frontend/src/pages/cr/Approvals.jsx  (line 143-145)
        pending.sort(... createdAt ...)   <- JavaScript sort, oldest first
    Aur abhi CR list mein se KOI BHI note review kar sakta hai (line tod ke).

3. QUEUE OPERATIONS -> PROJECT MEIN MATLAB
------------------------------------------------------------
    | Operation   | Project mein                                     |
    |-------------|--------------------------------------------------|
    | enqueue     | student ne notes submit kiye -> line mein peeche |
    | peek/front  | CR ko "Next to review" wala note                 |
    | dequeue     | CR ne approve / reject kiya -> line se bahar     |
    | size        | "5 notes waiting"                                |
    | isEmpty     | "No submissions waiting"                         |
    | traverse    | line mein har note ki position (#1 , #2 , #3 ..) |

C mein structure (idea):
    struct Note{
        int index;          // backend ki list mein kaunsa note (wapas pehchaanne ke liye)
        long long time;     // kab submit hua (createdAt, milliseconds)
        int mine;           // 1 = yeh note us student ka hai jo dekh raha hai (position ke liye)
    };

    struct Queue{
        struct Note items[MAX];
        int front;
        int rear;
    };

    + functions: enqueue , dequeue , peek , isEmpty , size , display/traverse

6. INPUT / OUTPUT FORMAT (idea)
------------------------------------------------------------
INPUT (backend -> C, stdin se):
    line 1 = kaam:   line   /   front   /   position
    line 2 = kitne pending notes hain
    phir   = har note ki ek line (SUBMIT KE ORDER mein, pehla sabse purana)
             index  time  mine

Example (4 pending notes, index 2 aur 3 is student ke hain):
    0 1700000100 0
    1 1700000500 0
    2 1700000900 1
    3 1700001200 1

--- (A) line ---                    OUTPUT:
    line                            4          <- size
    4                               0 1 2 3    <- front se rear tak
    0 1700000100 0
    ...

--- (B) front ---                   OUTPUT:
    front                           0          <- front pe index 0
    4                               (khaali queue ho toh: -1)
    0 1700000100 0
    ...

--- (C) position ---                OUTPUT:
    position                        2 3        <- index 2 line mein #3 pe
    4                               3 4        <- index 3 line mein #4 pe
    0 1700000100 0
    ...
