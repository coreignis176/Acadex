KYA KARTI HAI
    Form mein jo bhara gaya, woh sahi hai ya nahi - C++ check karti hai.

    Example: admin naya student add karta hai
        Name : R      Class Roll : 12      College Roll : 2510121
    Rule: naam 2 se 60 letters  ->  "R" galat
    Admin ko dikhega: "Student name must be 2-60 characters"
    (admin ko wahi dikhega jo abhi dikhta hai - bas check JS ki jagah C++ karegi)

KAHAN USE HOGI
    | # | Website pe                              | Frontend page                         | Backend line jo C++ se badlegi                |
    |---|-----------------------------------------|---------------------------------------|-----------------------------------------------|
    | 1 | Admin ek student add kare               | pages/admin/StudentPopup.jsx          | adminController.js:470  studentFieldError     |
    | 2 | Admin student edit kare                 | pages/admin/StudentDetailsPopup.jsx   | adminController.js:528  studentFieldError     |
    | 3 | Admin section banaye + CSV se students  | pages/admin/AddSectionPopup.jsx       | adminController.js:227  studentFieldError (har row) |
    | 4 | Password badle                          | components/ChangePassword.jsx         | UserController.js:140   passwordProblem (line 112) |
    | 5 | Admin subject add kare                  | pages/admin/SectionSubjects.jsx       | adminController.js:792  subjectProblem        |
    | 6 | Admin subject edit kare                 | pages/admin/SectionSubjects.jsx       | adminController.js:831  subjectProblem        |
    | 7 | Admin doosre section se subjects copy   | pages/admin/SectionSubjects.jsx       | adminController.js:904  subjectProblem        |
    | 8 | Student notes upload (title/topic/desc) | pages/student/UploadNotes.jsx         | notesController.js:313-324                    |

    1 , 2 , 3 teeno ek hi function (studentFieldError) -> ek C++ program se teen features.

OOP DESIGN
    Project ke saare checks sirf kuch tarah ke rules hain:

    | Rule ki type          | Example                                     |
    |-----------------------|---------------------------------------------|
    | Length rule           | naam 2-60 , password 8-64 , title 4-80      |
    | Allowed letters rule  | roll no mein sirf A-Z , 0-9 , -             |
    | Must have a letter    | password / naam mein kam se kam ek letter   |
    | Must have a digit     | password mein kam se kam ek number          |
    | Not same as           | password default password jaisa na ho       |

                      Rule                      <- parent (ABSTRACT class)
             "har rule ka ek check() function"     virtual bool check(string) = 0
            /        |          |          \       virtual string message()
     LengthRule  LettersRule  HasLetter  HasDigit  NotSameAs     <- children (INHERITANCE)

    Har form ka field = rules ki list:
        Name     = [ LengthRule(2,60) , HasLetterRule ]
        Password = [ LengthRule(8,64) , HasLetterRule , HasDigitRule , NotSameAsRule(default) ]
        Roll No  = [ LengthRule(1,10) , LettersRule("A-Z0-9-") ]

    EK loop sab check karta hai:
        for har rule in list:
            agar rule->check(text) fail  ->  rule ka message print , ruk jao

    = POLYMORPHISM: loop ko pata hi nahi rule kaunsa hai, bas check() bulata hai,
      har object apna khud ka check chalata hai.

    Field class -> uske paas vector<Rule*>   = COMPOSITION (Field "has" Rules)

INPUT / OUTPUT (idea)
    input:   student                  <- kaunsa form
             Rahul Singh              <- naam
             12                       <- class roll
             2510121                  <- college roll

    output:  ok
      ya:    Class roll number can use up to 10 letters, digits or hyphens

VIVA LINE
    "Naam, password, roll number, subject code, notes title - har form ki checking
     EK hi C++ program karta hai. Ek abstract class Rule banayi, usse kai child classes,
     aur ek loop polymorphism se sab rules check karta hai.
     Naya rule chahiye toh sirf ek nayi child class likho - purana code nahi badalta."
