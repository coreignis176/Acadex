3. C KO POORE NOTES NAHI, SIRF ZAROORI CHEEZEIN
------------------------------------------------------------
Ek note mein bahut kuch hota hai (files ke URL, description,
likes ki IDs ...). Woh sab C mein padhna mushkil hai aur chahiye bhi nahi.

C ko bas yeh bhejna hai:
    index    -> 0 , 1 , 2 ... (wapas pehchaanne ke liye ki kaunsa note tha)
    time     -> createdAt number mein (milliseconds)   -> Newest First
    likes    -> likes ki GINTI (note.likes.length)     -> Most Liked
    subject  -> subject ka naam                        -> Subject filter

C wapas bhejega sirf ORDER (indexes), poore notes nahi.
Backend phir:  sorted = order.map(i => notes[i])

Subject filter mein C sirf matching notes ke indexes bhejega,
baaki notes order mein aayenge hi nahi -> wahi "filter" hai.

C mein structure (idea):
    struct Note{
        int index;
        long long time;      // time bahut bada number hai -> long long
        int likes;
        char subject[61];    // subject ka naam
    };
