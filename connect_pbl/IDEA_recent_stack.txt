1. MAQSAD
------------------------------------------------------------
Student jo bhi note kholta hai, woh uski "history" mein SABSE UPAR aa jaaye,
jaise browser ki history. Jo sabse LAST khola, woh sabse PEHLE dikhe.
Yahi STACK hai: Last In First Out.

    Khole:  Trees -> DBMS -> Stack basics

    Stack:  [Trees] [DBMS] [Stack basics]  <- TOP
    Page pe dikhega (top se neeche):  Stack basics , DBMS , Trees

    DBMS dobara khola  -> purani jagah se hatao -> TOP pe push
    Stack:  [Trees] [Stack basics] [DBMS]  <- TOP

    Limit (jaise 10) se zyada -> sabse purana (BOTTOM) hata do

Student ko fayda: "jo abhi padh raha tha, wahin wapas jao" - ek click mein.

Yeh stack HUMARA C PROGRAM sambhalega, JavaScript nahi.

3. STACK OPERATIONS -> PROJECT MEIN MATLAB
------------------------------------------------------------
    | Operation    | Project mein                                          |
    |--------------|-------------------------------------------------------|
    | push         | student ne koi note khola -> top pe                   |
    | peek / top   | "Continue reading" wala note                          |
    | pop          | (andar ka kaam) - duplicate / purana hatane ke liye   |
    | isEmpty      | "No history yet" dikhana                              |
    | isFull       | limit poori -> bottom wala hatana padega              |
    | traverse     | History page pe top se bottom tak list                |
    | clear        | "Clear history" button                                |

C mein structure (idea):

        int top;              // -1 = khaali
    };
    + functions: push , pop , peek , isEmpty , isFull , display , clear

Notes ki id (string) hi stack mein jaayegi -> C mein strings ka stack.


4. DO MUSHKIL KAAM, SIRF STACK OPERATIONS SE (viva ke liye important)
------------------------------------------------------------
Pure stack mein sirf TOP pe kaam hota hai. Lekin humein do kaam
"beech" se aur "neeche" se karne hain:

  (a) DUPLICATE: DBMS pehle se beech mein hai, dobara khola
  (b) FULL: limit poori, sabse neeche (bottom) wala hatana hai

Dono ko SIRF push/pop se karenge, ek TEMP STACK ki madad se:

  (a) duplicate hatana:
        main stack se pop karte jao -> temp stack mein push
        jab woh id mile -> use phenk do (push mat karo)
        temp se pop karke wapas main mein push
        -> phir nayi id main pe push (top)

  (b) bottom hatana:
        main se sab pop -> temp mein push
        temp ka top (= main ka bottom) phenk do
        baaki temp se pop karke wapas main mein push

Isse koi array ka beech wala index seedha nahi chhua -> stack PURE rahega.
Viva mein seedha bol sakte hain: "do stacks se duplicate aur overflow handle kiya".
